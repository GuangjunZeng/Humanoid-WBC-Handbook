# HoST：从多姿态中学会平稳起身

来源：[arXiv:2502.08378v2](https://arxiv.org/abs/2502.08378v2) · [固定提交官方代码](https://github.com/OpenRobotLab/HoST/tree/70bb580949a336a920833700e4b5dc3bf7fe87ce)

解读范围：完整 13 页正文、限制与附录。

## 方法主线

HoST 不依赖示范轨迹，而是在 Isaac Gym 中从随机动作探索起身。策略输入是 IMU/编码器得到的基座角速度、横滚/俯仰、关节位置与速度、上一动作、动作缩放系数，以及过去五帧状态；输出 23 个关节的相对位置增量。目标经 `pᵈ_t = p_t + βa_t` 变成 PD 目标，再由 `τ_t = K_p(pᵈ_t-p_t)-K_d ṗ_t` 产生力矩。

训练同时解决三件事。第一，按基座高度把起身划为翻正、抬升、站稳三阶段，并把任务、风格、正则、站稳后目标拆给四个 critic；各 critic 单独估计优势，再标准化加权进入 PPO。第二，早期在躯干接近竖直时施加向上拉力，达到目标头高后从 200 N 每次减 20 N，帮助策略跨过“倒地到跪姿”的探索瓶颈。第三，动作缩放 `β` 从 1 逐步减到 0.25，并叠加 L2C2 与动作二阶差分正则，约束暴力触地、快速反弹和振荡。四类训练地形是地面、平台、墙面和斜坡；域随机化覆盖质量/质心、摩擦、增益、力矩扰动、控制延迟与初始姿态。

## 关键证据

- Figure 2：训练链路是状态/奖励 → 多 critic 策略 → 动作缩放 → 200 Hz PD；实机为 50 Hz 策略与 500 Hz PD。
- Equations 1–3：分别定义相对关节目标/PD 力矩、多 critic 值函数和加权优势 PPO。
- Table II：给出质量、质心、摩擦、增益、力矩、延迟和初始关节角等随机化范围。
- Table III：去掉多 critic 后四类地形成功率均为 0；去掉拉力时除平台外基本失败；去掉动作边界虽多处能起身，但脚移、平滑与能耗明显恶化。
- Table IV / Figure 7：G1 每类场景 5 次；完整方法 20/20，去掉 L2C2 为 11/20，且完整方法总体平滑指标更低。
- Figures 9–10 / Table V：实机相图显示关节速度仍有仿真差异；负载测试到 12 kg 时为 2/3，随机力矩丢失率 0.2 时为 0/3。

最强证据是 Table III 与 Table IV 的组合：前者用每策略 5 轮、每轮 250 episode 的仿真消融识别关键组件，后者用同一结构在 G1 上给出小样本但有分母的实机结果。它支持“多 critic、探索辅助和运动约束共同有用”，不支持把 20/20 外推为任意姿态或环境的安全保证。

## 论文—代码映射

| 组件 | 固定提交符号 | 对应关系 |
|---|---|---|
| 拉力与动作幅度课程 | `HostGround.step` / `HostGround.update_force_curriculum` | 在物理步中施加竖直拉力，并按起身进度降低拉力与 `action_rescale` |

| 复现实验 | `eval_ground.py` 等四类评估脚本 | 统计成功、脚位移、平滑度和能耗，并关闭训练期拉力 |

## 局限与安全边界

作者明确指出：纯本体感觉在户外会发生起身碰撞；仰卧与俯卧联合训练相互干扰；尚未接入完整人形系统；实机关节速度暴露出力矩建模差异；H1/H1-2 的偏差来源仍不清楚。独立判断是：策略把接触状态隐式编码在历史中，无法检查环境间隙或手臂落点；20 次主实机试验、负载 3 次试验也不足以建立故障概率。

起身/跌倒恢复是硬件高风险能力。论文的拉力、`β`、PD 增益、12 kg 负载和坡度都不是其他机器人可照搬的命令限值。复现必须先做固定种子仿真与碰撞审计，再做有支撑的低速单姿态测试；同时具备独立急停、限流/限温、柔性落地区、防夹碰隔离和专职安全员，最后才逐步扩展到不同接触面与无支撑恢复。
