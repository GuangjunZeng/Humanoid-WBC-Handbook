# AMP: Learning a Style Reward from Motion Distribution

[中文版](../amp-2104.02180.md)

Sources: [arXiv:2104.02180](https://arxiv.org/abs/2104.02180) · [pinned official implementation](https://github.com/isaac-sim/IsaacGymEnvs/tree/aeed298638a1f7b5421b38f5f3cc2d1079b6d9c3)

Review scope: the complete twenty-page paper and appendices, including task reward, hyperparameters, ablations, and official IsaacGymEnvs AMP code. The experiments use simulated characters, not real humanoid robots.

> In one sentence: a discriminator compares policy state transitions with unlabeled motion data to produce a task-independent style reward, enabling navigation, dribbling, and striking without per-clip tracking; it reduces reward engineering but remains vulnerable to mode collapse and data coverage.

Key terms include adversarial motion prior (对抗运动先验), style reward (风格奖励), task reward (任务奖励), generative adversarial imitation learning (生成对抗模仿学习), state transition (状态转移), discriminator (判别器), gradient penalty (梯度惩罚), replay buffer (回放缓冲区), mode collapse (模式坍塌), and occupancy distribution (占用分布).

## Engineering problem

DeepMimic aligns each clip by phase and computes reference pose error. At larger scale, clip selection, alignment, and weights become expensive, while “natural motion” is hard to hand-code. AMP asks whether unlabeled clips can define a reusable style signal.

Task and style must remain separate. Navigation only specifies a target, while data may contain walking, running, jumping, and rolling. The policy should select behavior from context rather than annotated clip schedules—like giving an actor style examples and a stage objective instead of a frame-by-frame script.

Adversarial learning is unstable. An overpowered discriminator gives no useful policy gradient; a weak one accepts artifacts; changing policy distribution causes forgetting. Gradient penalty, replay, RSI, and ET are therefore central.

## Core insight

AMP matches local state transitions to the motion distribution rather than one clip. Features include root velocity, joint rotation and velocity, and relative endpoint positions in a local frame, reducing dependence on global location and heading.

Task reward `r^G` and style reward `r^S` are combined, often with 0.5 weights. The paper uses a least-squares discriminator and bounded reward, while the later official code uses a log-probability form with the same purpose; formula and implementation version must not be conflated.

Gradient penalty constrains discriminator slope near real motion, while policy replay preserves old negative examples. The referee reviews old mistakes and cannot draw an infinitely sharp boundary near training samples.

## Method: input → processing → output

The environment produces `(s_t,s_{t+1})`; the task computes goal reward, and the discriminator computes style. PPO updates policy and value, while demonstration, current policy, and replay transitions train the discriminator. RSI samples motion states and ET removes failure.

The policy has 1024 and 512 hidden units, with Bullet at 1.2 kHz and policy at 30 Hz. Tasks use roughly 100–300M samples and 30–140 hours on sixteen CPU cores. The largest set contains 56 clips, eight actors, and 434 seconds.

Tasks include heading, location, dribbling, striking, obstacles, and stepping stones. Data has no task annotation, while the task reward selects useful modes. Spatial composition still requires high-level structure.

## Strongest experiment

The strongest result is one unlabeled dataset producing task-specific skills across several objectives, combined with feature and gradient-penalty ablations. It demonstrates a separable style interface and identifies mechanisms that stabilize it.

The failure evidence is equally important: front-flip pose error is approximately 0.425 versus 0.278 for tracking, and AMP may select only a local mode. “Prior” does not mean uniform use of all data.

## Limitations and safety boundary

The authors explicitly identify mode collapse, policy-specific retraining of the prior, task dependence in generated data, limited spatial composition, and unnatural local optima.

Independent limitations include only 434 seconds at maximum scale, exploitable discriminator score, missing actuator and sensor realism, and absent deployment thresholds for seed variance, calibration, and out-of-distribution scoring.

Style reward is not a safety prior. Hardware needs torque, contact, collision, CoP, thermal, state monitoring, and fallback. Discriminator output on unseen hazardous states may be arbitrary and cannot replace constraints.

## Bounded engineering takeaway

AMP is useful when task is easy to specify and natural style is hard to write. Motion data defines behavior and task reward defines purpose; evaluate them independently and monitor coverage rather than average discriminator score alone.

For humanoid WBC, retarget and repair contacts before prior training. Slip, unreachable joints, and impacts in data become learned style defects.

## Reproduction and acceptance checklist

Pin motions, rate, features, frame, RSI/ET, PPO, discriminator, replay, penalty, commit, and seeds. Reproduce no-penalty, no-velocity, and no-replay ablations and log accuracy, logits, task return, pose error, and mode coverage.

Calibrate on held-out motion, timing, mirror, speed, and adversarial artifacts. Report task and style separately across seeds and preserve collapse and reward-hacking trajectories.

Before robot transfer, add actuator, delay, noise, contact, and limits, with an external safety layer. Stage low-dynamic styles under tether, emergency stop, isolation, and current/thermal watchdog.

> **Engineering judgment:** AMP learns what motion data appears to allow, not what hardware physics and safety allow; those require clean data and explicit constraints.
